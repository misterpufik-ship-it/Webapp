# Локальный сайт анкеты

## Запуск

```powershell
cd local-site
python -m http.server 8765 --bind 0.0.0.0
```

Открой в браузере: **http://localhost:8765**

Чтобы Настя открыла с телефона в той же Wi‑Fi: **http://&lt;твой-IP&gt;:8765** (узнать: `ipconfig`).

## Как пользоваться

1. Никита — имя, анкета, скачать JSON.
2. Настя — тот же адрес, своё имя, своя анкета, свой JSON.
3. JSON можно потом подключить к backend (шаг 2).

Данные хранятся в `localStorage` браузера; приватный вопрос B3 помечен в интерфейсе.
